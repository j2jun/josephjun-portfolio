# Joseph Jun — Portfolio

Personal portfolio site built with Next.js (App Router) and Tailwind CSS v4, deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stack

- Next.js 16 (App Router, TypeScript)
- Tailwind CSS v4
- next/font (Space Grotesk, Public Sans, IBM Plex Mono)
- Deployed on Vercel with automatic preview deployments per PR
